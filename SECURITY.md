# Relate uma vulnerabilidade de segurança

Não relate vulnerabilidades de segurança em uma issue ou pull request público.

Use o [formulário privado de vulnerabilidade do GitHub](https://github.com/brunobracaioli/base-app/security/advisories/new) para contatar o mantenedor em particular. Inclua a versão ou o commit afetado, o impacto e os passos para reproduzir. Não inclua dados reais de usuários, credenciais ativas ou segredos sem mascaramento.

O formulário só recebe relatos depois que o mantenedor habilitar o recurso de relato privado neste repositório. A habilitação precisa ser confirmada antes de o repositório ser publicado. Não publique os detalhes até que haja uma correção ou um plano de divulgação coordenada.
